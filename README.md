# PlanMinds

PlanMinds is an AI-powered schedule organizer that helps users manage tasks, routines, and schedules seamlessly.

## Architecture

The project consists of a FastAPI backend and a React Native/Expo mobile app.

- **Backend:** FastAPI, PostgreSQL, Alembic, SQLAlchemy, Redis (for scheduler/workers).
- **Mobile:** React Native (Expo), TypeScript, React Query, Zustand.
